# AI & ML Internship – Task 11  
## SVM – Breast Cancer Classification

### 📌 Overview
This repository contains Task 11 of the AI & ML Internship, focusing on kernel-based classification using Support Vector Machines.

---

### 🛠 Tools Used
- Python
- Scikit-learn
- Matplotlib
- Jupyter Notebook

---

### 📁 Dataset
- Sklearn Breast Cancer Dataset

---

### 🔍 Steps Performed
- Data loading and inspection
- Feature scaling using StandardScaler
- Linear and RBF kernel comparison
- Hyperparameter tuning using GridSearchCV
- Model evaluation using confusion matrix, ROC & AUC
- Saved trained model for reuse

---

### 📊 Final Outcome
The task provided hands-on experience with SVM kernels, margin optimization, and hyperparameter tuning.
